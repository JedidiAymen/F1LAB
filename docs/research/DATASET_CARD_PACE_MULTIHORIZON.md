# Dataset card — exploratory multi-horizon Race Pace

**Status:** implemented research dataset with material selection and provenance limitations. Source is the existing OpenF1-derived Race Pace frame, 83,523 rows across 85 races; source SHA-256 `993cfaeb810883509bd9348e98a3b8a700813f4f509eeddcec22bd2c2e190ece`. Original source: https://openf1.org; the existing project data card describes CC BY-NC-SA 4.0/non-commercial restrictions. Raw responses and derived row-level data are not redistributed here. See [prior research](RACE_PACE_INTELLIGENCE.md) and [protocol and results](RACE_PACE_MULTIHORIZON_PROTOCOL.md); source completeness and provider publication times are not established by the hash.

Each decision row is an inherited race/driver/lap key with at least two exact-key recorded durations from laps L through L−2. Targets are recorded lap L+1, L+3 or L+5, joined by exact source keys; missing intermediate records or missing target are counted and excluded. The inherited frame already requires a consecutive next lap with an end time. Therefore the dataset is future-record-selected and cannot measure all real decisions, retirements or live reliability. Outcome categories are retrospectively inferred and can incorporate later information; they are never model inputs. Weather and timing values are timestamp-aligned in the prior frame, but actual publication latency is unverified.

Build from the archived frame with the commands in the protocol; rows and model artifacts are retained only in the local research directory. Expanding race-grouped chronology uses 20 initial training races then three test races per fold. Races were previously inspected; there is no untouched confirmatory holdout.
