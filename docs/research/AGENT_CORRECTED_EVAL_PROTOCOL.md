Registered 2026-11-01 before this run. This is stacked on PR #3 at `0b9c14b46cd6de7a03c1d983e1def95edf3d9c6e` and compares the original foundation agent at `5cdac66677e6abb513f84e3ede5f74dd74d00bb6` against the corrected PR #1 agent at `486bba76f092ce1bd0862a9ac2ff41c0640fd96e`. Both use the same eight synthetic fault families and seeds 1 and 4 as EXP-AGENT-PAIRED-01; these are **previously inspected cases**, not unseen faults or a confirmatory generalization test. The corrected candidate includes unknown/missing-evidence handling and the foundation integration; it was not the candidate in the original 6/16 result.

Use the unchanged PR #3 paired harness, local Ollama `qwen3:8b` digest recorded in the run, temperature 0, seed 42, 4,096 context tokens, 512 output tokens, up to six agent steps, alternating arm order, two CPU threads, timeout and failure rules as frozen by the harness. Preserve every actual case/trace and any errors; no repeated tuning or omitted denominator. Measure root-cause label accuracy, false no-discrepancy, invalid/undetermined outcomes, invalid citation IDs, tool calls/errors and elapsed time. A recognized citation ID does not imply semantic support: evidence-support scoring is pending separate human/engineering adjudication of actual traces, and must not be inferred from label accuracy. Bootstrap intervals resample the eight known fault families only and do not quantify real incident performance. No multi-fault or incomplete-evidence capability is inferred from this single-fault benchmark.

The experiment writes to a new output directory and never overwrites the earlier PR #3 evidence. If resource limits, missing model, transport or worker errors prevent completion, retain the partial run and report exact errors. This is research, not an agent promotion or automatic diagnosis.

## Actual results — 2026-11-01

The frozen local Ollama evaluation completed 32/32 investigations with no failed workers. Foundation and corrected candidate each identified 6/16 labels correctly (37.5%); paired accuracy difference 0.0 percentage points, 95% bootstrap over eight known families [−37.5, +37.5] points. False no-discrepancy decisions were 8 and 10 respectively; invalid/undetermined diagnoses and nonexistent citation IDs were 0 in each arm. The agents made 47 and 16 tool calls, with no tool errors. Mean elapsed times were 15.35 and 14.27 seconds; p95 20.13 and 28.05 seconds. The run resumed after interruption on a shared machine, so timing differences are not controlled speed measurements.

A deliberately targeted, unblinded engineering review examined six candidate explanations. For `feature_skew-s1` and `feature_skew-s4`, the explanation asserted feature alignment while its cited `t1` reported 4,320/4,320 tyre-age mismatches. `missing_live_data-s4` asserted no missing data although `t1` recorded 661 batch-only keys. The `missing_live_data-s1` coverage-consistency claim did not account for 668 batch-only keys. In `unit_mismatch-s1` and `unit_mismatch-s4`, the claim that mean gaps were within noise lacked a cited bound; the reported values were 10,061.14196 and 15,004.98635 seconds. These are reviews of particular claims, not complete explanation judgments or a representative evidence-support score. Other candidate cases and all baseline cases remain unreviewed.

To run a new evaluation, create separate clean worktrees at the exact frozen revisions, ensure the same local Ollama model and Python dependencies are present, and choose an empty destination. Output will differ with inference/runtime nondeterminism:

```bash
PYTHONPATH=src .venv/bin/python -m f1_racelab.agents.forecast_debug.paired --baseline-root /path/to/foundation-worktree --candidate-root /path/to/corrected-pr1-worktree --out /path/to/new-run
PYTHONPATH=src .venv/bin/python scripts/publish_corrected_agent_eval.py --source /path/to/new-run --out /path/to/new-projection
```

To resume a partial compatible run, repeat the first command with `--resume`. Do not overwrite original artifacts. The selected review is a separate manual artifact and is not regenerated by the projection script.
