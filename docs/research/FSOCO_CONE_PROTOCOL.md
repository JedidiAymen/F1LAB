# Frozen exploratory protocol: Formula Student cone detection

Registered 2026-11-01, before downloading the selected images, looking at held-out predictions, or running training. Status: preregistered; no model results yet. This is autonomous Formula Student cone perception, not Formula 1 footage or race-car detection.

Source: [FSOCO overview](https://fsoco.github.io/fsoco-dataset/overview/) describes manually annotated cone boxes, and its [download page](https://fsoco.github.io/fsoco-dataset/download) makes its training dataset publicly available for cone detection. Its official bounding-box ZIP served over HTTP identifies 24,839,341,525 bytes, accepts HTTP byte ranges, and its archive index was inspected with 1,895,057 bytes. The official website repository's MIT code license is not asserted to license the data. Redistribution permission and source-image licenses are not established; keep the images and annotations local, cite FSOCO, and do not bundle imagery. Unencrypted HTTP is a provenance limitation, not authenticated source integrity.

Population: the official public training archive, not its hidden benchmark. Freeze selection by team and lexicographic image name before viewing model results: first 25 matching image/annotation pairs each from `ampera`, `amz`, `aristurtle`, `asurt` for training (up to 100); first 20 from `baltic` for validation and first 20 from `bauman` for testing. Team is an archive folder, not proof of independent venues or recording sequences. Each image must have its matching rectangle annotation; map all labeled cone colors/types to one cone class. Keep truncation and difficult objects; report invalid or unrecognized records rather than silently fabricate labels. Use no venue/circuit claims.

Fixed candidate: torchvision pretrained COCO SSDLite320 MobileNet V3 Large, replace its classification head for background + cone, initialize the remaining detector from COCO weights, fine-tune on the selected training set with seed 42, 3 epochs, SGD learning rate 0.001 and momentum 0.9, batch size 4, no augmentation beyond the model's fixed 320-pixel transform. Use validation only for monitoring; do not change protocol based on test results. Fixed baseline: the unmodified COCO detector with its predicted categories collapsed to a single class for class-agnostic cone matching; COCO has no cone class, so its score is a transfer reference, not a specialized cone detector. Evaluate both once on the team-held-out test set using COCO box mAP@50 and mAP@50:95, precision/recall where available, latency and failures. Report every result including negative results; a 20-image one-team test is exploratory, not a generalized field estimate. Report full source/model hashes, exclusions, model and package licenses, hardware and exact commands.

Do not promote a serving model or assert tracking, independent sequence splits, real-world vehicle detection, model quality or CV completion from this small study. Reserve at most 300 MB downloaded source bytes and do not replace any existing artifacts. If the detector stack, sample access, licenses or evaluation cannot be established, record the exact blocker instead of claiming completion.

## Pre-download correction: conservative filename-prefix split

Archive-index inspection before image download revealed that folder names do not reliably describe filename prefixes: for example, `ampera` contains `amz_*.png`, and `bauman` contains `amz_*.png`. The initially registered folder split could therefore place a shared filename group across train and test. No selected images or model results had been inspected. Replace the folder split with a deterministic filename-prefix split over the archive: train prefixes `amz`, `BME`, `mms`, `ff` (first 25 matching image/annotation pairs per prefix, sorted by full archive path); validation prefix `ka` (first 20); test prefix `gfr` (first 20). Include `.jpg` and `.png` case-insensitively. Prefix is only a conservative grouping heuristic: its relationship to actual recording sequence, venue or contributor is unverified, and distinct prefixes may still be related. Keep the initial registration above as an audit trail; every other protocol condition remains unchanged. Do not call this a team- or circuit-held-out benchmark.
