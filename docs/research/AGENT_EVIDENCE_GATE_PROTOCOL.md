# Forecast Debug observational evidence gate — exploratory protocol

Registered on 2026-11-01 before running this gate, on PR #1 head `486bba76f092ce1bd0862a9ac2ff41c0640fd96e`. This is a narrow decision-support experiment, not a root-cause classifier, production approval or a fresh holdout. The saved Qwen3 results and some failure cases were already inspected. It is stacked on PR #1; the paired trace data used for offline evaluation come from the independently stacked PR #10. No branch is merged.

Input is a proposed diagnosis with explicit citation IDs and bounded observations produced by `incident_checks`. Before interpreting any field, require unique, existing cited tool IDs and well-formed JSON. Represent missing, invalid or unrecognized evidence as insufficient. Inspect only cited `incident_checks`; never query the database or trust uncited observations. Detect these observable signals: positive batch-only/live-only forecast keys, known model-version disagreements, known config differences, known feature-value mismatches, previous-lap alignment hints, and an absolute live/batch magnitude ratio of at least 10 when batch magnitude is at least one second. The ratio is a coarse warning, not proof of a units error. These signals are factual or heuristic observations, not causal conclusions.

Policy: any `no_material_discrepancy` proposal is **abstained**, including when no signal is found, because this summary cannot exclude every failure mode. If a positive signal is found, mark that proposal contradicted and return the observed signals. Missing/invalid evidence also abstains, never establishes a mismatch or a clean bill. For any other proposed diagnosis, return the supported observations and require review; never automatically approve a root cause. The proposed label remains visible as an unverified proposal.

Evaluate offline on all 16 corrected-candidate cases from the actual prior Qwen3 paired study; do not rerun or change the LLM. Report how many false-clean decisions are withheld, how many genuinely clean cases are also withheld, how many are contradicted by selected deterministic signals versus only abstained, and any invalid/missing evidence. These safety statistics follow directly from the deliberately conservative policy; withholding every clean decision trivially prevents false-clean outputs and is not an accuracy improvement. Do not compute or imply a validated causal diagnosis, semantic support rate, independent test result, or generalization to real incidents. Preserve the original 6/16 result, all source hashes and original traces. Add adversarial synthetic tests for unknown and conflicting values, missing citations, malformed observations and multiple signals.

## Post-hoc hardening amendment

The first frozen gate at `f027c48714eb81aee61eac979649b5137ab5a5b3` was replayed once on the previously inspected cases; its report is retained. After seeing that aggregate, an adversarial test found that malformed config-difference entries containing placeholder `unknown` could be treated as known. The gate was hardened to reject placeholder values and to bound mismatch counts by known pairs. This is a correctness fix made **after** initial results were seen, not a blind experiment. The same cases will be replayed once more for regression only; any outcome is post-hoc and cannot establish generalization or a tuned improvement. The opt-in wrapper retains the original agent diagnosis and appends a separate gate result; default inference is unchanged.
