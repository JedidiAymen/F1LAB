SHA-256 sidecar contain aggregate scores, training curves, model/data/source
hashes, units/contracts references and limitations. `independent_verification.json`
records a separate metric/reload check. `local_artifact_manifest.json` lists the

telemetry are not redistributed. The source-cache audit preserves both response
identities. Source: OpenF1 historical API, https://openf1.org/docs/; repository
