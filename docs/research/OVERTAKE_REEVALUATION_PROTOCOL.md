# Corrected overtake retrospective reevaluation protocol

Registered 2026-11-01 before rebuilding the dataset or fitting models. This is an exploratory rerun on already-inspected events, not a fresh holdout, an unconditional live forecast or a confirmed on-track pass model. The source is the same saved Race Pace frame identified by SHA-256 `993cfaeb810883509bd9348e98a3b8a700813f4f509eeddcec22bd2c2e190ece`; source coverage and provider publication timestamps remain uncertain. The target remains next recorded-lap timing-order swap, with pit/neutralization outcomes used retrospectively to exclude cases. Apply the corrected cutoff and consecutive-record checks and calculate historical circuit prior rates only from races with strictly earlier start times.

Use the existing fixed expanding race-group walk-forward protocol (minimum 20 training races; steps of three); compare constant prior, gap-only logistic, all-feature logistic, raw LightGBM and isotonic-calibrated LightGBM. Preserve existing fixed hyperparameters and chronological calibration; do not tune on these inspected events. Report Brier, log-loss, AUC, average precision, calibration error and paired race-clustered bootstrap intervals. Preserve individual race/lap/pair identifiers in scored predictions, save per-fold fitted artifacts and hashes locally, and compare summary metrics against the prior published run only descriptively: the datasets differ and scores are not a clean paired estimate of model improvement. Keep the original source and old artifacts unchanged, write to new directories, and document exact code/data hashes and limitations. No trained model will be promoted for live inference.
