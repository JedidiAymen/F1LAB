# Race Pace multi-horizon study — registered protocol

Registered before this study's fitting or outcome inspection on 2026-11-01, starting at foundation `5cdac66677e6abb513f84e3ede5f74dd74d00bb6`. This is an exploratory extension on races already inspected in earlier research, not a fresh independent confirmatory test.

At the end of lap L, forecast the recorded duration of lap L+h for h ∈ {1, 3, 5}, in seconds. Use the existing Race Pace frame and its decision-time calm population (`pace.strict.decision_frame`), including its known provider-latency and source-coverage limitations. Construct targets only by an exact same-race/same-driver join to lap L+h−1's `next_lap_seconds`; never use later observations as features. Require a recorded target and report how many eligible decision rows are censored at each horizon; this evaluation is conditional on the target being recorded and is not a retirement-aware or unconditional race forecast. Missing intermediate records must not be silently treated as a continuous trajectory. Include disrupted, pit, wet and neutralised target laps where recorded; do not use future outcomes to select the population or choose model inputs. Report retrospective outcome breakdowns separately and label them as such.

Direct horizon-specific forecasts use only the strict L-time feature set, with tyre state reconstructed from lap L as a stay-out assumption. Compare the L-time last-known clean lap, the rolling median anchor, and an L1 LightGBM residual model anchored on that median. Also include the existing post-pit persistence rule for h=1; it uses an earlier-training-race median after a known in-lap. Do not claim that this one-lap rule is optimal for later horizons. Fit independent q10 and q90 LightGBM residuals for descriptive uncertainty; report coverage, width, quantile crossings and pinball loss without asserting valid calibration. No future tyre changes, pit events or neutralisation labels may be inputs.

Use expanding chronological race-grouped folds, first 20 races train-only and next 3 races per test fold, matching prior study; all preprocessing and pit-rule statistics fit on training races only. Freeze hyperparameters to existing bundle defaults and seed 42. For each horizon report MAE, median absolute error, RMSE, per-season/per-race errors, and paired LightGBM-minus-last-known-clean MAE with 5,000 race-clustered bootstrap draws, seed 42. Preserve all censored-row counts and negative findings. Validate exact target joins, no feature leakage, chronological disjointness and hashes; persist fold model artifacts and keyed predictions in a new immutable local run directory, plus software/source/version metadata. Distinguish missing or duplicate source identities from valid absence. Do not overwrite the original pace study.

The existing OpenF1-derived source is non-commercial per the prior data card and raw responses are not redistributed. The source-integrity audit identified questionable cached responses elsewhere; this existing frame remains subject to the documented coverage limitations. No source completeness is inferred from a valid hash. Reproducibility, API/UI integration, trained artifacts and full tests must precede any claim of completed milestone.
